GitHub token

The proxy reads the module repositories (and, for automatic updates, its own repository) with this token. It is never shown here. Before it expires, create a new one on GitHub, paste it below and save it: it is used at once. Test setup checks the token and every repository; with a token in the field it tests that one without saving it.
