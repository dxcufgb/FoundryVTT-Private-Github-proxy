GitHub token

The proxy reads the module repositories (and, for automatic updates, its own repository) with this token. It is never shown here. Before it expires, create a new one on GitHub and add it here: GitHub must accept it first, then it is used at once. Test setup checks the token and every repository.

    Notifications

    E-mails go to every address below when the proxy updates itself (or an automatic update fails; automatic updates are turned on with the installer) and when its daily check finds a problem: a token GitHub no longer accepts, or a repository the token cannot read.
